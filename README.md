# 💬 Cmess - Корпоративный Консольный Мессенджер

**Cmess** — это легковесный кроссплатформенный консольный мессенджер, написанный на C++ с использованием сокетов.  
Проект предназначен для обмена сообщениями в локальной корпоративной сети без использования сторонних серверов.

---

## 🚀 Возможности

- **Клиент-серверная архитектура** — поддержка нескольких клиентов одновременно.
- **Real-time общение** — мгновенная передача сообщений между пользователями.
- **Кроссплатформенность** — поддержка Windows и Linux.
- **Консольный UI** — ANSI-последовательности для обновления интерфейса без дублирования сообщений.
- **Валидация ввода** — защита от отправки пустых сообщений.
- **Юнит-тесты** — тестирование сериализации пакетов и вспомогательной логики.
- **Минимальные зависимости** — использование STL и системных сетевых API.

# ⚙️ Сборка проекта

## Требования

### Windows
- Visual Studio 2022 Community
- CMake
- vcpkg
- Boost
- Google Test

### Linux
- GCC / Clang с поддержкой C++17
- CMake
- Ninja
- Boost
- pthread

---

## 📦 Установка зависимостей (Windows)

Установите необходимые библиотеки через vcpkg:

```bash
vcpkg install boost gtest
```

Перед сборкой задайте переменную окружения:

```bash
set VCPKG_ROOT=C:\vcpkg
```

---

## 🪟 Сборка на Windows

Проект можно открыть напрямую через Visual Studio Community с поддержкой CMake.

Либо собрать вручную:

```bash
mkdir build
cd build

cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build .
```

---

## 🐧 Сборка на Linux

```bash
mkdir build
cd build

cmake .. -G Ninja -DCMAKE_BUILD_TYPE=Release
ninja
```
